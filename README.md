# 📘 Decimal Learning

A simple and interactive web application designed to help students learn and practice decimal concepts.

## 🌐 Live Demo

[Decimal Learning](https://dena-shibu.github.io/decimal-learning/)

## 📖 About the Project

Decimal Learning is a React-based educational web application focused on helping students understand and practice decimals.

The application provides learning material, interactive practice questions, and a quiz section where users can test their understanding.

## ✨ Features

* 📚 **Learn** — Learn basic concepts related to decimals.
* ✏️ **Practice** — Practice decimal questions and receive immediate feedback.
* 📝 **Quiz** — Take a quiz with a set of decimal-related questions and receive a score.
* ℹ️ **About** — Information about the application.
* 📱 **Responsive UI** — Designed to work across different screen sizes.
* 🎨 **Styled Interface** — Uses CSS and Tailwind CSS for the user interface.

## 🛠️ Technologies Used

* **React.js** — Building the user interface and components
* **JavaScript** — Application logic
* **HTML** — Page structure
* **CSS** — Styling
* **Tailwind CSS** — Utility-based styling
* **Vite** — Development and build tool
* **Git & GitHub** — Version control
* **GitHub Pages** — Deployment

## 🧠 React Concepts Used

This project helped implement several React concepts, including:

* `useState`
* State management
* Event handling
* Controlled inputs
* Arrays and objects
* Conditional rendering
* Component-based development

For example, the Practice section stores user answers and results using React state and checks each answer against the corresponding correct answer.

## 🚀 Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/Dena-Shibu/decimal-learning.git
```

Move into the project directory:

```bash
cd decimal-learning
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.

## 📦 Building the Project

To create a production build:

```bash
npm run build
```

## 🚀 Deployment

The project is deployed using GitHub Pages.

To deploy an updated version:

```bash
npm run deploy
```

## 🎯 Project Goal

The goal of Decimal Learning is to provide a simple, interactive way for students to learn decimal concepts and practice what they have learned through immediate feedback and quizzes.
